synapticTrack

Open-source beam-physics and machine-learning building blocks for accelerator research.

Public Scope

This site documents reusable software contracts: beam-state representations, deterministic sampling, dataset schemas, surrogate inference, metrics, and extension interfaces.

Machine configurations, operational procedures, lattice sources, diagnostics, measurements, and tracking runtimes are not published here.
