Beam Physics and ML

The public library provides uncoupled transverse Gaussian beam-state utilities, covariance checks, Courant-Snyder derived quantities, deterministic Sobol and Latin-hypercube sampling, PyTorch surrogate models, normalized metrics, and artifact-validation helpers.

Use an explicit dataset schema and an explicit surrogate schema when loading a model.
