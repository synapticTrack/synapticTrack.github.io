Core Contracts

synapticTrack.core provides named parameter and observation contracts, sampling plans, versioned dataset contracts, tracking requests/results, validity masks, and portable failure categories.

Machine adapters implement these contracts with explicit configuration and provenance. The core library does not select a lattice, executable path, or device-specific default.
